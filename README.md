# irealty-proposal

A single-page product roadmap proposal for the i-realty.app real estate platform. The page presents the planned phases, milestones and charts for the work.

## Contents

| File | Purpose |
| --- | --- |
| `index.html` | The whole site: markup, styles and scripts in one file |
| `CNAME` | Custom domain for the static host: `irealty-proposal.cuesoft.io` |

## Run locally

There is no build step. Open `index.html` in a browser. Tailwind CSS, Chart.js and the Plus Jakarta Sans font load from their public CDNs, so an internet connection is needed to render the page as designed.

## Deploy

The site is static. Publish the repository root with any static host; the `CNAME` file sets the custom domain for hosts that read it, such as GitHub Pages. A change to `main` is the whole release.
