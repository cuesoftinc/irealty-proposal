# Contributing

Thanks for your interest in improving this project.

## Getting started

1. Fork the repository and clone your fork.
2. Create a focused branch.

The site is one static page, `index.html`, with no build step. It loads
Tailwind CSS, Chart.js and a web font from their public CDNs. Open the file in
a browser to preview a change.

## Before opening a pull request

Check the page in a browser at phone, tablet and desktop widths, confirm the
charts render and the browser console shows no errors.

Branches are named `<feature|bugfix>/<short-description>`. Use Conventional
Commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`), keep changes
focused, and never commit credentials or `.env` files.

## Code review

At least one approving review from a maintainer is required before merge. Be
responsive to review feedback.

## Code of Conduct

Participation is governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
